# Asset Prompts

These are deterministic generation prompts for the local build script, not instructions to scrape or copy reference assets.

| Asset Area | Prompt Record |
| --- | --- |
| Brand system | Create an original Nameplate mark and wordmark using Personal brand with clean essays, author authority, newsletter focus, and simple navigation and palette #fffdf8, #17233c, #c09a4a, #17233c, #3f6f6b. |
| Hero system | Generate local vector hero assets for Editorial author hero without copying inspiration-site photography, UI, code, or brand assets. |
| Section system | Create one section visual, one icon, and three card thumbnails per section using Author portraits, books, essays, podcast and speaking panels. |
| Mockups/diagrams | Use abstract original dummy-data interfaces and diagrams for Author essay and media system; no copied dashboards, maps, or product screenshots. |
| Utility/social | Create local utility visuals, favicons, Apple icon, PNG icons, and page-specific OG previews. |

## Asset Handoff Documentation

The public site no longer exposes an asset-system HTML route. Asset inventories remain in the docs folder and local asset tree for QA and handoff; public navigation uses only the 10 core pages and 7 universal utility pages.
