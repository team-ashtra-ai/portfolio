# Asset Prompts

These are deterministic generation prompts for the local build script, not instructions to scrape or copy reference assets.

| Asset Area | Prompt Record |
| --- | --- |
| Brand system | Create an original OrbitDesk mark and wordmark using Dark product system with glass UI, fine borders, gradient light, and app panels and palette #08090d, #5e6ad2, #9b8cff, #f7f8ff, #37d67a. |
| Hero system | Generate local vector hero assets for App interface hero without copying inspiration-site photography, UI, code, or brand assets. |
| Section system | Create one section visual, one icon, and three card thumbnails per section using Dark app screens, issue boards, roadmap panels. |
| Mockups/diagrams | Use abstract original dummy-data interfaces and diagrams for Dark product dashboard system; no copied dashboards, maps, or product screenshots. |
| Utility/social | Create local utility visuals, favicons, Apple icon, PNG icons, and page-specific OG previews. |

## Asset Handoff Documentation

The public site no longer exposes an asset-system HTML route. Asset inventories remain in the docs folder and local asset tree for QA and handoff; public navigation uses only the 10 core pages and 7 universal utility pages.
