# Layout System

This site will not reuse the same layout structure as the previous sites.

This site will not use the same hero-card-grid-FAQ-CTA rhythm unless redesigned completely.

## Layout Difference Plan

| Layer | Rule |
| --- | --- |
| Overall layout archetype | Dark product dashboard system |
| Page width system | uses --container-sm/md/lg/xl/fluid with per-site values in css/styles.css |
| Container system | Dark product dashboard system containers with medium density |
| Section rhythm | paced around Subtle glow and panel reveal and varied section composition |
| Grid/column structure | Fine-line app cards and Fine-line app cards control grid emphasis |
| Asymmetry rules | each page rotates at least one asymmetric, full-bleed, sticky, or report-led section |
| Full-bleed rules | allowed for App interface hero, gallery, proof, and CTA moments only |
| Boxed/split rules | boxed surfaces use Dark product system with glass UI, fine borders, gradient light, and app panels; split sections must not repeat image-left/text-right by default |
| Sidebar/sticky rules | use only on resource, proof, contact, pricing, or utility pages when it supports conversion |
| Overlap/negative space | controlled by medium spacing and not copied from avoid-list sites |
| Visual hierarchy | Inter display with "Trebuchet MS" body and Verdana accent labels plus clear primary/secondary CTA hierarchy |
| Page density | medium |

Future edits should happen in this site folder rather than regenerating shared templates.

## Asset Handoff Documentation

The public site no longer exposes an asset-system HTML route. Asset inventories remain in the docs folder and local asset tree for QA and handoff; public navigation uses only the 10 core pages and 7 universal utility pages.
