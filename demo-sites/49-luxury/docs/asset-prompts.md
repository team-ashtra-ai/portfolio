These are deterministic generation prompts for the local build script, not instructions to scrape or copy reference assets.

| Asset Area | Prompt Record |
| --- | --- |
| Brand system | Create an original MaisonVale mark and wordmark using Luxury with deep green, gold restraint, heritage pacing, and private product focus and palette #081f18, #0b5f3a, #d4af37, #f4efe2, #111111. |
| Hero system | Generate local vector hero assets for Deep-green private hero without copying inspiration-site photography, UI, code, or brand assets. |
| Section system | Create one section visual, one icon, and three card thumbnails per section using Craft details, watches, private rooms, heritage materials. |
| Mockups/diagrams | Use abstract original dummy-data interfaces and diagrams for Heritage luxury maison; no copied dashboards, maps, or product screenshots. |
| Utility/social | Create local utility visuals, favicons, Apple icon, PNG icons, and page-specific OG previews. |

## Asset Handoff Documentation

The public site no longer exposes an asset-system HTML route. Asset inventories remain in the docs folder and local asset tree for QA and handoff; public navigation uses only the 10 core pages and 7 universal utility pages.
