# WordPress Export

Future custom theme mapping: header, footer, core page templates, resource templates, FAQ/contact/legal templates, image fields, SEO fields, navigation, footer sitemap, and form configuration. Do not use Elementor or paid builder dependency. Preserve the static design system and accessibility rules.

## Section Field Contract

Each `wp-template-section` is ready for optional export as a reusable template part, Gutenberg block, ACF flexible content block, or dynamic PHP partial. Required editable fields are exposed through the section attributes: admin title, visibility, layout variation, background style, eyebrow, heading, subheading, body, optional media, alt text, repeater items, proof/stat/testimonial data, CTA labels and URLs, alignment, theme colour, image position, and mobile stacking rule.
