# Layout System

This site will not reuse the same layout structure as the previous sites.

This site will not use the same hero-card-grid-FAQ-CTA rhythm unless redesigned completely.

## Layout Difference Plan

| Layer | Rule |
| --- | --- |
| Overall layout archetype | Minimal energy product landing |
| Page width system | uses --container-sm/md/lg/xl/fluid with per-site values in css/styles.css |
| Container system | Minimal energy product landing containers with medium density |
| Section rhythm | paced around Clean product reveal and varied section composition |
| Grid/column structure | Product output cards and Product output cards control grid emphasis |
| Asymmetry rules | each page rotates at least one asymmetric, full-bleed, sticky, or report-led section |
| Full-bleed rules | allowed for Centered product hero, gallery, proof, and CTA moments only |
| Boxed/split rules | boxed surfaces use Minimal product marketing with stark surfaces, centered copy, and energy-product proof; split sections must not repeat image-left/text-right by default |
| Sidebar/sticky rules | use only on resource, proof, contact, pricing, or utility pages when it supports conversion |
| Overlap/negative space | controlled by medium spacing and not copied from avoid-list sites |
| Visual hierarchy | "Palatino Linotype" display with Inter body and "Segoe UI" accent labels plus clear primary/secondary CTA hierarchy |
| Page density | medium |
