# Asset Prompts

These are deterministic generation prompts for the local build script, not instructions to scrape or copy reference assets.

| Asset Area | Prompt Record |
| --- | --- |
| Brand system | Create an original PawHealth mark and wordmark using Veterinary care with warm clinic colours, rounded forms, and friendly triage and palette #fff7ef, #256a5e, #ffb199, #256a5e, #21413a. |
| Hero system | Generate local vector hero assets for Warm appointment hero without copying inspiration-site photography, UI, code, or brand assets. |
| Section system | Create one section visual, one icon, and three card thumbnails per section using Clinic rooms, pets, care teams, appointment panels. |
| Mockups/diagrams | Use abstract original dummy-data interfaces and diagrams for Modern clinic care flow; no copied dashboards, maps, or product screenshots. |
| Utility/social | Create local utility visuals, favicons, Apple icon, PNG icons, and page-specific OG previews. |

## Asset Handoff Documentation

The public site no longer exposes an asset-system HTML route. Asset inventories remain in the docs folder and local asset tree for QA and handoff; public navigation uses only the 10 core pages and 7 universal utility pages.
