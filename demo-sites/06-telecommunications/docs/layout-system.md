# Layout System

This site will not reuse the same layout structure as the previous sites.

This site will not use the same hero-card-grid-FAQ-CTA rhythm unless redesigned completely.

| Layer | Rule |
| --- | --- |
| Overall layout archetype | Space coverage landing |
| Page width system | uses --container-sm/md/lg/xl/fluid with per-site values in css/styles.css |
| Container system | Space coverage landing containers with practical density |
| Section rhythm | paced around Slow parallax and signal reveal and varied section composition |
| Grid/column structure | Satellite coverage cards and Satellite coverage cards control grid emphasis |
| Asymmetry rules | each page rotates at least one asymmetric, full-bleed, sticky, or report-led section |
| Full-bleed rules | allowed for Black full-bleed coverage hero, gallery, proof, and CTA moments only |
| Boxed/split rules | boxed surfaces use Black space utility with full-bleed contrast, uppercase navigation, and availability CTAs; split sections must not repeat image-left/text-right by default |
| Sidebar/sticky rules | use only on resource, proof, contact, pricing, or utility pages when it supports conversion |
| Overlap/negative space | controlled by practical spacing and not copied from avoid-list sites |
| Visual hierarchy | Inter display with Aptos body and "Trebuchet MS" accent labels plus clear primary/secondary CTA hierarchy |
| Page density | practical |
