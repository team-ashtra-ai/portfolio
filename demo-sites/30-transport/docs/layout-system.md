# Layout System

This site will not reuse the same layout structure as the previous sites.

This site will not use the same hero-card-grid-FAQ-CTA rhythm unless redesigned completely.

## Layout Difference Plan

| Layer | Rule |
| --- | --- |
| Overall layout archetype | Map-first route planner |
| Page width system | uses --container-sm/md/lg/xl/fluid with per-site values in css/styles.css |
| Container system | Map-first route planner containers with practical density |
| Section rhythm | paced around Route line reveal and varied section composition |
| Grid/column structure | Transit route cards and Transit route cards control grid emphasis |
| Asymmetry rules | each page rotates at least one asymmetric, full-bleed, sticky, or report-led section |
| Full-bleed rules | allowed for Green transit planner hero, gallery, proof, and CTA moments only |
| Boxed/split rules | boxed surfaces use Transit utility with bright green, map-first decisions, and route cards; split sections must not repeat image-left/text-right by default |
| Sidebar/sticky rules | use only on resource, proof, contact, pricing, or utility pages when it supports conversion |
| Overlap/negative space | controlled by practical spacing and not copied from avoid-list sites |
| Visual hierarchy | Aptos display with Inter body and Constantia accent labels plus clear primary/secondary CTA hierarchy |
| Page density | practical |

The public site no longer exposes an asset-system HTML route. Asset inventories remain in the docs folder and local asset tree for QA and handoff; public navigation uses only the 10 core pages and 7 universal utility pages.
