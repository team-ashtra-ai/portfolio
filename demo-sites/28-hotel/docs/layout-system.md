# Layout System

This site will not reuse the same layout structure as the previous sites.

This site will not use the same hero-card-grid-FAQ-CTA rhythm unless redesigned completely.

## Layout Difference Plan

| Layer | Rule |
| --- | --- |
| Overall layout archetype | Quiet retreat booking flow |
| Page width system | uses --container-sm/md/lg/xl/fluid with per-site values in css/styles.css |
| Container system | Quiet retreat booking flow containers with spacious density |
| Section rhythm | paced around Slow luxury fade and varied section composition |
| Grid/column structure | Retreat room cards and Retreat room cards control grid emphasis |
| Asymmetry rules | each page rotates at least one asymmetric, full-bleed, sticky, or report-led section |
| Full-bleed rules | allowed for Serene full-bleed stay hero, gallery, proof, and CTA moments only |
| Boxed/split rules | boxed surfaces use Hospitality with quiet luxury, large tranquil imagery, and restrained booking paths; split sections must not repeat image-left/text-right by default |
| Sidebar/sticky rules | use only on resource, proof, contact, pricing, or utility pages when it supports conversion |
| Overlap/negative space | controlled by spacious spacing and not copied from avoid-list sites |
| Visual hierarchy | "Palatino Linotype" display with Aptos body and Didot accent labels plus clear primary/secondary CTA hierarchy |
| Page density | spacious |

## Static Authorship Pass

This site folder is now treated as the editable static source for `StayHaven`. The duplicate secondary header route strip was removed from the static HTML, and the footer markup/CSS was rewritten directly in the site files using the `immersive` footer pattern for the `Aman` inspiration direction. Future edits should happen in this site folder rather than regenerating shared templates.

## Asset Handoff Documentation

The public site no longer exposes an asset-system HTML route. Asset inventories remain in the docs folder and local asset tree for QA and handoff; public navigation uses only the 10 core pages and 7 universal utility pages.

## Portfolio Section Component Pass - 2026-05-11

StayHaven now treats every main-body section as a static, WordPress-ready component with a component ID, section type, layout variation, pattern family, mobile stacking rule, and editable field map. The pass keeps the Aman inspiration as a principle reference only while using original local markup, CSS, JS, and assets. Repeated section names are deliberately varied so Hero, Services, Process, Results, FAQ, Contact, and CTA patterns do not collapse into one shared layout.
