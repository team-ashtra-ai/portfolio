# Asset Prompts

These are deterministic generation prompts for the local build script, not instructions to scrape or copy reference assets.

| Asset Area | Prompt Record |
| --- | --- |
| Brand system | Create an original StayHaven mark and wordmark using Hospitality with quiet luxury, large tranquil imagery, and restrained booking paths and palette #f3efe7, #2f2a24, #b89b72, #2f2a24, #6c756b. |
| Hero system | Generate local vector hero assets for Serene full-bleed stay hero without copying inspiration-site photography, UI, code, or brand assets. |
| Section system | Create one section visual, one icon, and three card thumbnails per section using Villas, landscapes, spa spaces, calm interiors. |
| Mockups/diagrams | Use abstract original dummy-data interfaces and diagrams for Quiet retreat booking flow; no copied dashboards, maps, or product screenshots. |
| Utility/social | Create local utility visuals, favicons, Apple icon, PNG icons, and page-specific OG previews. |

## Asset Handoff Documentation

The public site no longer exposes an asset-system HTML route. Asset inventories remain in the docs folder and local asset tree for QA and handoff; public navigation uses only the 10 core pages and 7 universal utility pages.
