# Asset Prompts

These are deterministic generation prompts for the local build script, not instructions to scrape or copy reference assets.

| Asset Area | Prompt Record |
| --- | --- |
| Brand system | Create an original TerraMetric mark and wordmark using Climate software with serious green, evidence dashboards, and enterprise clarity and palette #f4fbf7, #083d31, #00a878, #083d31, #244bff. |
| Hero system | Generate local vector hero assets for Emissions dashboard hero without copying inspiration-site photography, UI, code, or brand assets. |
| Section system | Create one section visual, one icon, and three card thumbnails per section using Carbon dashboards, climate reports, data rooms. |
| Mockups/diagrams | Use abstract original dummy-data interfaces and diagrams for Climate data operating system; no copied dashboards, maps, or product screenshots. |
| Utility/social | Create local utility visuals, favicons, Apple icon, PNG icons, and page-specific OG previews. |
