# Asset Prompts

These are deterministic generation prompts for the local build script, not instructions to scrape or copy reference assets.

| Asset Area | Prompt Record |
| --- | --- |
| Brand system | Create an original LineWorks mark and wordmark using Manufacturing product clarity with precise specs, orange highlights, and printer-like panels and palette #f8f8f8, #111111, #ff5f1f, #111111, #6b7280. |
| Hero system | Generate local vector hero assets for Precision product hero without copying inspiration-site photography, UI, code, or brand assets. |
| Section system | Create one section visual, one icon, and three card thumbnails per section using 3D printers, material samples, production benches. |
| Mockups/diagrams | Use abstract original dummy-data interfaces and diagrams for Industrial product specification; no copied dashboards, maps, or product screenshots. |
| Utility/social | Create local utility visuals, favicons, Apple icon, PNG icons, and page-specific OG previews. |

## Asset Handoff Documentation

The public site no longer exposes an asset-system HTML route. Asset inventories remain in the docs folder and local asset tree for QA and handoff; public navigation uses only the 10 core pages and 7 universal utility pages.
