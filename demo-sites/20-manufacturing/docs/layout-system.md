# Layout System

This site will not reuse the same layout structure as the previous sites.

This site will not use the same hero-card-grid-FAQ-CTA rhythm unless redesigned completely.

## Layout Difference Plan

| Layer | Rule |
| --- | --- |
| Overall layout archetype | Industrial product specification |
| Page width system | uses --container-sm/md/lg/xl/fluid with per-site values in css/styles.css |
| Container system | Industrial product specification containers with dense density |
| Section rhythm | paced around Spec table reveal and varied section composition |
| Grid/column structure | Specification cards and Specification cards control grid emphasis |
| Asymmetry rules | each page rotates at least one asymmetric, full-bleed, sticky, or report-led section |
| Full-bleed rules | allowed for Precision product hero, gallery, proof, and CTA moments only |
| Boxed/split rules | boxed surfaces use Manufacturing product clarity with precise specs, orange highlights, and printer-like panels; split sections must not repeat image-left/text-right by default |
| Sidebar/sticky rules | use only on resource, proof, contact, pricing, or utility pages when it supports conversion |
| Overlap/negative space | controlled by dense spacing and not copied from avoid-list sites |
| Visual hierarchy | "Trebuchet MS" display with Aptos body and Didot accent labels plus clear primary/secondary CTA hierarchy |
| Page density | dense |
