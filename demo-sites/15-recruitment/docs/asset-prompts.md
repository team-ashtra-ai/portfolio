# Asset Prompts

These are deterministic generation prompts for the local build script, not instructions to scrape or copy reference assets.

| Asset Area | Prompt Record |
| --- | --- |
| Brand system | Create an original TalentBridge mark and wordmark using Hiring editorial with yellow blocks, human stories, and job-board modules and palette #ffe45e, #111111, #ff6a3d, #111111, #1f6feb. |
| Hero system | Generate local vector hero assets for Yellow job magazine hero without copying inspiration-site photography, UI, code, or brand assets. |
| Section system | Create one section visual, one icon, and three card thumbnails per section using Workplace portraits, job cards, culture pages. |
| Mockups/diagrams | Use abstract original dummy-data interfaces and diagrams for Editorial talent marketplace; no copied dashboards, maps, or product screenshots. |
| Utility/social | Create local utility visuals, favicons, Apple icon, PNG icons, and page-specific OG previews. |

## Asset Handoff Documentation

The public site no longer exposes an asset-system HTML route. Asset inventories remain in the docs folder and local asset tree for QA and handoff; public navigation uses only the 10 core pages and 7 universal utility pages.
