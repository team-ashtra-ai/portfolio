# Asset Prompts

These are deterministic generation prompts for the local build script, not instructions to scrape or copy reference assets.

| Asset Area | Prompt Record |
| --- | --- |
| Brand system | Create an original WaveCast mark and wordmark using Media system with black surfaces, neon accents, angular modules, and dense story grids and palette #0b0b13, #e2127a, #fff200, #ffffff, #00d4ff. |
| Hero system | Generate local vector hero assets for Angular media hero without copying inspiration-site photography, UI, code, or brand assets. |
| Section system | Create one section visual, one icon, and three card thumbnails per section using News cards, studio images, episode panels, neon lines. |
| Mockups/diagrams | Use abstract original dummy-data interfaces and diagrams for Neon editorial news grid; no copied dashboards, maps, or product screenshots. |
| Utility/social | Create local utility visuals, favicons, Apple icon, PNG icons, and page-specific OG previews. |

## Asset Handoff Documentation

The public site no longer exposes an asset-system HTML route. Asset inventories remain in the docs folder and local asset tree for QA and handoff; public navigation uses only the 10 core pages and 7 universal utility pages.
