# Asset Prompts

These are deterministic generation prompts for the local build script, not instructions to scrape or copy reference assets.

| Asset Area | Prompt Record |
| --- | --- |
| Brand system | Create an original NexusOps mark and wordmark using Infrastructure marketing with orange CTAs, network diagrams, and dense product routes and palette #fff7ed, #f38020, #faae40, #18191f, #ffe4c2. |
| Hero system | Generate local vector hero assets for Network diagram hero without copying inspiration-site photography, UI, code, or brand assets. |
| Section system | Create one section visual, one icon, and three card thumbnails per section using Edge maps, server nodes, operational dashboards. |
| Mockups/diagrams | Use abstract original dummy-data interfaces and diagrams for Edge network product system; no copied dashboards, maps, or product screenshots. |
| Utility/social | Create local utility visuals, favicons, Apple icon, PNG icons, and page-specific OG previews. |
