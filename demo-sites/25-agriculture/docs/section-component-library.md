## WordPress Field Contract

Every `wp-template-section` includes `data-component-id`, `data-section-type`, `data-section-label`, `data-layout-variation`, `data-pattern-family`, `data-wp-fields`, `data-mobile-stack`, and `data-theme-surface`. These map cleanly to an ACF flexible-content block, Gutenberg block, template part, or PHP partial without requiring a page builder.

## Design Intent

The section system is designed around Vertical farm growth system. Repeated names such as Hero, Services, Process, Results, Questions, Contact, and CTA are intentionally assigned different pattern families so the site reads as a portfolio of reusable front-end components rather than a repeated content template.
