# Asset Prompts

These are deterministic generation prompts for the local build script, not instructions to scrape or copy reference assets.

| Asset Area | Prompt Record |
| --- | --- |
| Brand system | Create an original IndexHouse mark and wordmark using Publishing with print cadence, yellow accents, compact columns, and editorial authority and palette #f7efd2, #111111, #f6c400, #111111, #8c1d18. |
| Hero system | Generate local vector hero assets for Editorial masthead hero without copying inspiration-site photography, UI, code, or brand assets. |
| Section system | Create one section visual, one icon, and three card thumbnails per section using Magazine spreads, desks, books, archive covers. |
| Mockups/diagrams | Use abstract original dummy-data interfaces and diagrams for Print magazine archive; no copied dashboards, maps, or product screenshots. |
| Utility/social | Create local utility visuals, favicons, Apple icon, PNG icons, and page-specific OG previews. |

## Asset Handoff Documentation

The public site no longer exposes an asset-system HTML route. Asset inventories remain in the docs folder and local asset tree for QA and handoff; public navigation uses only the 10 core pages and 7 universal utility pages.
