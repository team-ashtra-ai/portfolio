# Design Extraction

For every reference, extract principles rather than copying visible identity. The fixed ASH-TRA page and section matrix remains unchanged.

## 1. Monocle (direct)

URL: https://www.monocle.com/

| Extraction Field | Principle For This ASH-TRA Site |
| --- | --- |
| Layout archetype | Extract industry-specific publishing, information & knowledge platforms credibility; translate into Print magazine archive rather than copying Monocle. |
| Header structure | Borrow the decision logic of a direct reference, then rebuild as Print index header. |
| Desktop navigation style | Use clear route grouping for fixed ASH-TRA pages with density tuned to medium. |
| Mobile menu behaviour | Adapt mobile cues into Primary-reference mobile navigation with static-content fallback. |
| Footer structure | Use sitemap completeness and trust routing, rebuilt as archive footer. |
| Typography mood | Study the mood, then express it through Verdana display with "Trebuchet MS" body and Inter accent labels. |
| Colour palette | Translate reference contrast into the original palette #f7efd2, #111111, #f6c400, #111111, #8c1d18. |
| Surface system | Use surface hierarchy ideas only; final surfaces are Publishing with print cadence, yellow accents, compact columns, and editorial authority. |
| Hero type | Use the reference to pressure-test the first screen, then build an original Editorial masthead hero. |
| Section rhythm | Extract pacing lessons and apply varied fixed-section composition, not a copied sequence. |
| Card design | Convert card intent into Column article cards with unique spacing, shape, and state rules. |
| Form pattern | Use friction and reassurance cues to refine the original Newsletter form. |
| CTA flow | Map intent to Primary-reference CTA hierarchy using Subscribe and primary CTA `Subscribe`. |
| Asset direction | Translate asset principles into Magazine spreads, desks, books, archive covers and local ASH-TRA assets. |
| Image treatment | Use crop/contrast lessons without using the reference images, crops, or art direction directly. |
| Icon/illustration style | Extract clarity and hierarchy only; final icon language stays local to IndexHouse. |
| JS interaction ideas | Use as inspiration for Library search, author filter, newsletter modal while preserving readable static content. |
| Motion style | Reduce or reshape motion into Print-column reveal with reduced-motion support. |
| Mobile behaviour | Apply mobile task priority to Primary-reference mobile navigation and responsive section rhythm. |
| What must not be copied | Do not copy code, copy, logos, images, brand assets, exact layouts, exact animations, or proprietary identity. |

## Originality Commitment

Inspired by these patterns, this ASH-TRA site will use an original design system with different branding, copy, layout, CSS, assets, and interactions.

## Static Authorship Pass

This site folder is now treated as the editable static source for `IndexHouse`. The duplicate secondary header route strip was removed from the static HTML, and the footer markup/CSS was rewritten directly in the site files using the `editorial` footer pattern for the `Monocle` inspiration direction. Future edits should happen in this site folder rather than regenerating shared templates.

## Portfolio Section Component Pass - 2026-05-11

IndexHouse now treats every main-body section as a static, WordPress-ready component with a component ID, section type, layout variation, pattern family, mobile stacking rule, and editable field map. The pass keeps the Monocle inspiration as a principle reference only while using original local markup, CSS, JS, and assets. Repeated section names are deliberately varied so Hero, Services, Process, Results, FAQ, Contact, and CTA patterns do not collapse into one shared layout.


## Homepage Atlas Pass - 2026-05-12

- Homepage content now remains hero-first and CTA-final; the notes/disclaimer block is placed before the final CTA so the page closes on `Subscribe`.
- The hero secondary CTA scrolls to `#site-atlas`, and the atlas links every core page plus support, legal, sitemap, recovery, and asset-system routes.
- Homepage section text links now route deeper into the site instead of looping back to Home.
- Atlas variant: `constellation` for `Index`, shaped by `Print magazine archive`, `Column article cards`, `Library search, author filter, newsletter modal`, and `editorial` mobile behaviour.
- No new external inspiration was added; the existing reference pack remains the source for layout, header, navigation, footer, typography, colour, cards, forms, assets, motion, mobile behaviour, and non-copy rules.


## Portfolio Visual QA Pass - 2026-05-12

- Section copy was tightened so reusable blocks explain `Index` with clearer role, proof, fit, and next-step language instead of repeated placeholder patterns.
- Generic card labels were replaced with section-purpose labels across services, trust, results, editorial, FAQ, and CTA blocks.
- CSS now keeps screenshot and no-JS states visible, disables problematic `content-visibility` reservations for portfolio review, prevents horizontal overflow, and avoids awkward mid-word breaks.
- The pass preserves each site's existing inspiration pack, local assets, component families, section rhythm, and cross-site identity while improving presentation quality across all pages.
