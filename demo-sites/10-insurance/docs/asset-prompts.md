These are deterministic generation prompts for the local build script, not instructions to scrape or copy reference assets.

| Asset Area | Prompt Record |
| --- | --- |
| Brand system | Create an original Shieldline mark and wordmark using Insurance quote flow with hot pink, friendly copy, and simple white cards and palette #fff2f7, #ff0083, #ffb3d9, #251024, #ffffff. |
| Hero system | Generate local vector hero assets for Friendly quote hero without copying inspiration-site photography, UI, code, or brand assets. |
| Section system | Create one section visual, one icon, and three card thumbnails per section using Quote flows, policy cards, soft character-free illustrations. |

## Static Asset System Page

`asset-system.html` displays local assets for brand, logo, favicon, images, video posters, icons, illustrations, typography, CSS, JavaScript, animation, SEO, Open Graph, social sharing, header, footer, form, analytics, cookie, accessibility, multilingual, blog, service, industry, case study, downloadable, legal, and trust/proof categories. Files live under this site's own `assets/` tree and are linked from the site navigation.
