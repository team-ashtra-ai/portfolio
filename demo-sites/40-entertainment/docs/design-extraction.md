# Design Extraction

For every reference, extract principles rather than copying visible identity. The fixed ASH-TRA page and section matrix remains unchanged.

## 1. A24 (direct)

URL: https://a24films.com/

| Extraction Field | Principle For This ASH-TRA Site |
| --- | --- |
| Layout archetype | Extract industry-specific entertainment, music & performance credibility; translate into Indie film poster system rather than copying A24. |
| Header structure | Borrow the decision logic of a direct reference, then rebuild as Film studio header. |
| Desktop navigation style | Use clear route grouping for fixed ASH-TRA pages with density tuned to theatrical. |
| Mobile menu behaviour | Adapt mobile cues into Primary-reference mobile navigation with static-content fallback. |
| Footer structure | Use sitemap completeness and trust routing, rebuilt as venue footer. |
| Typography mood | Study the mood, then express it through Verdana display with Georgia body and Arial accent labels. |
| Colour palette | Translate reference contrast into the original palette #050505, #ffffff, #c69a55, #ffffff, #e24a2e. |
| Surface system | Use surface hierarchy ideas only; final surfaces are Entertainment with black cinema mood, poster grids, and understated weirdness. |
| Hero type | Use the reference to pressure-test the first screen, then build an original Dark poster hero. |
| Section rhythm | Extract pacing lessons and apply varied fixed-section composition, not a copied sequence. |
| Card design | Convert card intent into Poster event cards with unique spacing, shape, and state rules. |
| Form pattern | Use friction and reassurance cues to refine the original Ticket enquiry form. |
| CTA flow | Map intent to Primary-reference CTA hierarchy using View Tickets and primary CTA `View Tickets`. |
| Asset direction | Translate asset principles into Film posters, stage stills, credits, audience moments and local ASH-TRA assets. |
| Image treatment | Use crop/contrast lessons without using the reference images, crops, or art direction directly. |
| Icon/illustration style | Extract clarity and hierarchy only; final icon language stays local to StageCurrent. |
| JS interaction ideas | Use as inspiration for Event calendar, ticket selector, artist filter while preserving readable static content. |
| Motion style | Reduce or reshape motion into Poster fade reveal with reduced-motion support. |
| Mobile behaviour | Apply mobile task priority to Primary-reference mobile navigation and responsive section rhythm. |
| What must not be copied | Do not copy code, copy, logos, images, brand assets, exact layouts, exact animations, or proprietary identity. |

## Originality Commitment

Inspired by these patterns, this ASH-TRA site will use an original design system with different branding, copy, layout, CSS, assets, and interactions.

## Static Authorship Pass

This site folder is now treated as the editable static source for `StageCurrent`. The duplicate secondary header route strip was removed from the static HTML, and the footer markup/CSS was rewritten directly in the site files using the `immersive` footer pattern for the `A24` inspiration direction. Future edits should happen in this site folder rather than regenerating shared templates.

## Portfolio Section Component Pass - 2026-05-11

StageCurrent now treats every main-body section as a static, WordPress-ready component with a component ID, section type, layout variation, pattern family, mobile stacking rule, and editable field map. The pass keeps the A24 inspiration as a principle reference only while using original local markup, CSS, JS, and assets. Repeated section names are deliberately varied so Hero, Services, Process, Results, FAQ, Contact, and CTA patterns do not collapse into one shared layout.


## Homepage Atlas Pass - 2026-05-12

- Homepage content now remains hero-first and CTA-final; the notes/disclaimer block is placed before the final CTA so the page closes on `View Tickets`.
- The hero secondary CTA scrolls to `#site-atlas`, and the atlas links every core page plus support, legal, sitemap, recovery, and asset-system routes.
- Homepage section text links now route deeper into the site instead of looping back to Home.
- Atlas variant: `private` for `Stage`, shaped by `Indie film poster system`, `Poster event cards`, `Event calendar, ticket selector, artist filter`, and `dark` mobile behaviour.
- No new external inspiration was added; the existing reference pack remains the source for layout, header, navigation, footer, typography, colour, cards, forms, assets, motion, mobile behaviour, and non-copy rules.


## Portfolio Visual QA Pass - 2026-05-12

- Section copy was tightened so reusable blocks explain `Stage` with clearer role, proof, fit, and next-step language instead of repeated placeholder patterns.
- Generic card labels were replaced with section-purpose labels across services, trust, results, editorial, FAQ, and CTA blocks.
- CSS now keeps screenshot and no-JS states visible, disables problematic `content-visibility` reservations for portfolio review, prevents horizontal overflow, and avoids awkward mid-word breaks.
- The pass preserves each site's existing inspiration pack, local assets, component families, section rhythm, and cross-site identity while improving presentation quality across all pages.
