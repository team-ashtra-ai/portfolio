# Asset Prompts

These are deterministic generation prompts for the local build script, not instructions to scrape or copy reference assets.

| Asset Area | Prompt Record |
| --- | --- |
| Brand system | Create an original AtlasKind mark and wordmark using Travel editorial with black contrast, immersive destinations, and itinerary storytelling and palette #0b0b0b, #ffffff, #b4874a, #f1eee8, #8bb8e8. |
| Hero system | Generate local vector hero assets for Immersive trip hero without copying inspiration-site photography, UI, code, or brand assets. |
| Section system | Create one section visual, one icon, and three card thumbnails per section using Remote places, maps, itinerary details, travel photography. |
| Mockups/diagrams | Use abstract original dummy-data interfaces and diagrams for Dark destination magazine; no copied dashboards, maps, or product screenshots. |
| Utility/social | Create local utility visuals, favicons, Apple icon, PNG icons, and page-specific OG previews. |

## Asset Handoff Documentation

The public site no longer exposes an asset-system HTML route. Asset inventories remain in the docs folder and local asset tree for QA and handoff; public navigation uses only the 10 core pages and 7 universal utility pages.
