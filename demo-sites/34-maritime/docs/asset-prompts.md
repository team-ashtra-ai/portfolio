# Asset Prompts

These are deterministic generation prompts for the local build script, not instructions to scrape or copy reference assets.

| Asset Area | Prompt Record |
| --- | --- |
| Brand system | Create an original HarborLine mark and wordmark using Maritime corporate clarity with pale blue, logistics forms, and route tracking and palette #ecf8ff, #40b4e5, #9ad7f5, #003a5d, #003a5d. |
| Hero system | Generate local vector hero assets for Shipping route hero without copying inspiration-site photography, UI, code, or brand assets. |
| Section system | Create one section visual, one icon, and three card thumbnails per section using Ships, containers, ports, route maps, logistics docs. |
| Mockups/diagrams | Use abstract original dummy-data interfaces and diagrams for Blue ocean logistics portal; no copied dashboards, maps, or product screenshots. |
| Utility/social | Create local utility visuals, favicons, Apple icon, PNG icons, and page-specific OG previews. |

## Asset Handoff Documentation

The public site no longer exposes an asset-system HTML route. Asset inventories remain in the docs folder and local asset tree for QA and handoff; public navigation uses only the 10 core pages and 7 universal utility pages.
