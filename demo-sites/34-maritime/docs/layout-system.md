# Layout System

This site will not reuse the same layout structure as the previous sites.

This site will not use the same hero-card-grid-FAQ-CTA rhythm unless redesigned completely.

## Layout Difference Plan

| Layer | Rule |
| --- | --- |
| Overall layout archetype | Blue ocean logistics portal |
| Page width system | uses --container-sm/md/lg/xl/fluid with per-site values in css/styles.css |
| Container system | Blue ocean logistics portal containers with dense density |
| Section rhythm | paced around Route schedule reveal and varied section composition |
| Grid/column structure | Cargo service cards and Cargo service cards control grid emphasis |
| Asymmetry rules | each page rotates at least one asymmetric, full-bleed, sticky, or report-led section |
| Full-bleed rules | allowed for Shipping route hero, gallery, proof, and CTA moments only |
| Boxed/split rules | boxed surfaces use Maritime corporate clarity with pale blue, logistics forms, and route tracking; split sections must not repeat image-left/text-right by default |
| Sidebar/sticky rules | use only on resource, proof, contact, pricing, or utility pages when it supports conversion |
| Overlap/negative space | controlled by dense spacing and not copied from avoid-list sites |
| Visual hierarchy | Aptos display with Georgia body and Verdana accent labels plus clear primary/secondary CTA hierarchy |
| Page density | dense |
