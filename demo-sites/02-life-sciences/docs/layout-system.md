| Asymmetry rules | each page rotates at least one asymmetric, full-bleed, sticky, or report-led section |
| Full-bleed rules | allowed for AI biology lab hero, gallery, proof, and CTA moments only |
| Boxed/split rules | boxed surfaces use TechBio with dark scientific grids, microscopy panels, and pipeline evidence; split sections must not repeat image-left/text-right by default |
| Sidebar/sticky rules | use only on resource, proof, contact, pricing, or utility pages when it supports conversion |
| Overlap/negative space | controlled by compact spacing and not copied from avoid-list sites |
| Visual hierarchy | Inter display with "Segoe UI" body and Georgia accent labels plus clear primary/secondary CTA hierarchy |
| Page density | compact |
