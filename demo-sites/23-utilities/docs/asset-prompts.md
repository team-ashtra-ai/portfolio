# Asset Prompts

These are deterministic generation prompts for the local build script, not instructions to scrape or copy reference assets.

| Asset Area | Prompt Record |
| --- | --- |
| Brand system | Create an original ClearGrid mark and wordmark using Utilities with playful purple energy, rounded service blocks, and transparent tariff flow and palette #140021, #7f3cff, #ff4fd8, #f6f1ff, #00d1ff. |
| Hero system | Generate local vector hero assets for Purple service hero without copying inspiration-site photography, UI, code, or brand assets. |
| Section system | Create one section visual, one icon, and three card thumbnails per section using Energy accounts, meters, tariff calculators, service notices. |
| Mockups/diagrams | Use abstract original dummy-data interfaces and diagrams for Playful utility account flow; no copied dashboards, maps, or product screenshots. |
| Utility/social | Create local utility visuals, favicons, Apple icon, PNG icons, and page-specific OG previews. |

## Asset Handoff Documentation

The public site no longer exposes an asset-system HTML route. Asset inventories remain in the docs folder and local asset tree for QA and handoff; public navigation uses only the 10 core pages and 7 universal utility pages.
