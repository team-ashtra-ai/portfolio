# Layout System

This site will not reuse the same layout structure as the previous sites.

This site will not use the same hero-card-grid-FAQ-CTA rhythm unless redesigned completely.

## Layout Difference Plan

| Layer | Rule |
| --- | --- |
| Overall layout archetype | Playful utility account flow |
| Page width system | uses --container-sm/md/lg/xl/fluid with per-site values in css/styles.css |
| Container system | Playful utility account flow containers with practical density |
| Section rhythm | paced around Playful account reveal and varied section composition |
| Grid/column structure | Rounded tariff cards and Rounded tariff cards control grid emphasis |
| Asymmetry rules | each page rotates at least one asymmetric, full-bleed, sticky, or report-led section |
| Full-bleed rules | allowed for Purple service hero, gallery, proof, and CTA moments only |
| Boxed/split rules | boxed surfaces use Utilities with playful purple energy, rounded service blocks, and transparent tariff flow; split sections must not repeat image-left/text-right by default |
| Sidebar/sticky rules | use only on resource, proof, contact, pricing, or utility pages when it supports conversion |
| Overlap/negative space | controlled by practical spacing and not copied from avoid-list sites |
| Visual hierarchy | "Palatino Linotype" display with Arial body and Constantia accent labels plus clear primary/secondary CTA hierarchy |
| Page density | practical |
