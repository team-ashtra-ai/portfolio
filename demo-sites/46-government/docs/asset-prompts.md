# Asset Prompts

These are deterministic generation prompts for the local build script, not instructions to scrape or copy reference assets.

| Asset Area | Prompt Record |
| --- | --- |
| Brand system | Create an original CivicAccess mark and wordmark using Public service with plain language, blue actions, and high-contrast forms and palette #ffffff, #1d70b8, #ffdd00, #0b0c0c, #ffdd00. |
| Hero system | Generate local vector hero assets for Plain service hero without copying inspiration-site photography, UI, code, or brand assets. |
| Section system | Create one section visual, one icon, and three card thumbnails per section using Forms, service lists, notices, public task flows. |
| Mockups/diagrams | Use abstract original dummy-data interfaces and diagrams for Public service task flow; no copied dashboards, maps, or product screenshots. |
| Utility/social | Create local utility visuals, favicons, Apple icon, PNG icons, and page-specific OG previews. |

## Asset Handoff Documentation

The public site no longer exposes an asset-system HTML route. Asset inventories remain in the docs folder and local asset tree for QA and handoff; public navigation uses only the 10 core pages and 7 universal utility pages.
