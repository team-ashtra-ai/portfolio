# ASH-TRA 50 Website Inspiration And Diversity Brief

## Core Instruction

Do not design the 50 ASH-TRA websites from one visual template.

The page names and section names are fixed by the ASH-TRA matrix, so each site must differ through:

- layout archetype
- header style
- mobile menu style
- footer structure
- typography mood
- colour and surface system
- hero type
- section rhythm
- card design
- form pattern
- CTA flow
- asset direction
- JS interaction ideas
- motion style
- mobile behaviour

## Required Inspiration Process

Before building or rewriting each numbered site, create:

- `docs/inspiration-audit.md`
- `docs/design-extraction.md`
- `docs/theme-direction.md`
- `docs/layout-system.md`
- `docs/partials-system.md`
- `docs/component-system.md`
- `docs/asset-direction.md`
- `docs/js-interaction-plan.md`
- `docs/mobile-behaviour.md`
- `docs/cross-site-difference-report.md`

Each website must use at least 8 references:

- 3 direct industry references
- 2 adjacent industry references
- 2 contrast references from a different visual world
- 1 interaction or UI pattern reference

## Extraction Fields

For every inspiration reference, extract:

- layout archetype
- header structure
- desktop navigation style
- mobile menu behaviour
- footer structure
- typography mood
- colour palette
- surface system
- hero type
- section rhythm
- card design
- form pattern
- CTA flow
- asset direction
- image treatment
- icon/illustration style
- JS interaction ideas
- motion style
- mobile behaviour
- what must not be copied

## Non-Copy Rule

References are research inputs only. Do not copy code, copy, logos, images, brand assets, exact layouts, exact animations, or proprietary identity.

Inspired by these patterns, each ASH-TRA site must use an original design system with different branding, copy, layout, CSS, assets, and interactions.

## Acceptance Rule

A site fails if the only difference is colour, font, copy, images, or industry name.

A site passes only if it has a different layout architecture, partial design, CSS system, component style, asset world, interactive behaviour, mobile experience, conversion flow, page rhythm, and visual personality.
