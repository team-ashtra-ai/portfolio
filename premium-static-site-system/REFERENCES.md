# References

These references define the standards baseline for the checklist system. They do not replace project-specific legal, accessibility, security, or SEO review.

- WCAG 2.2 recommendation: https://www.w3.org/TR/WCAG22/

## Tooling Principle

- Prefer open formats, source control, dependency-free checks where possible, and replaceable free/open-source tools. Treat paid services as optional integrations, not core static-site requirements.
